# Adoção do Template de Michael Nygard para ADRs (Architecture Decision Records)

## Contexto:

Como etapa inicial da documentação do projeto, tornou-se necessário definir, previamente a qualquer decisão arquitetural, o modelo de registro que serviria de base para todas as demais documentações futuras.

Nesse cenário, com o objetivo de tornar os registros acessíveis e compreensíveis para qualquer pessoa interessada (não apenas o time de desenvolvimento) foram analisados alguns modelos amplamente adotados no mercado, tais como:
1. Markdown ADR;
2. Markdown ADR Light;
3. Nygard ADR Template;
4. Y-Statement Template;
5. Tech Radar (ThoughtWorks).

## Decisão:

Optou-se pela adoção do template proposto por Michael Nygard.

## Status:

Aceita em 11/12/2025.

## Consequências:

Por se tratar de um modelo simples, objetivo e amplamente reconhecido no mercado, sua adoção possibilita alinhar os padrões de documentação do projeto às exigências de diferentes stakeholders. Além disso, favorece o desenvolvimento das nossas competências enquanto estudantes, ao aproximar-nos de práticas e referenciais utilizados no ambiente profissional de engenharia de software.
